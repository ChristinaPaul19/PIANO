GENOVA SoundFont setup milestone (historical milestone 1 record)

Scope
-----
At milestone 1, the supplied workspace contained only FluidSynth, not an
existing GENOVA app. This setup-only GENOVA folder was created with approval.
No application code was replaced and no audio engine was implemented then.
config\audio.json is used by scripts\Test-SoundFont.ps1.

Milestone 2 added the approved Electron keyboard and independent audio engine.
Milestone 3 adds original drum/bass accompaniment and chord progression loops.
Both use the same configuration and SoundFont. See README.md for architecture,
controls, launch commands and verification.

Verification
------------
Run in PowerShell:
  & 'D:\Christina\Sound\GENOVA\scripts\Test-SoundFont.ps1'
For a silent offline render without live playback, add -RenderOnly.

The script creates a short original three-note MIDI, renders a WAV, checks
that its 16-bit PCM samples are non-silent, queries Windows audio devices,
and plays the same MIDI through FluidSynth's configured audio driver.
It uses no extra packages. Each subprocess has a 60-second timeout.
Evidence is saved under verification\, including result.json, logs, the MIDI,
and soundfont-test.wav. Each run replaces the previous verification output.

- Non-silent stereo WAV: 48000 Hz, 16-bit, 4.512 seconds including release tail.
